# AI Learn - Quick Start Guide

## 🚀 Get Started in 5 Minutes

### Step 1: Install Dependencies
```bash
# Windows
setup.bat

# Mac/Linux
bash setup.sh

# Or manually:
pip install -r requirements.txt
```

### Step 2: Run the Application
```bash
streamlit run app.py
```

### Step 3: Create Your Account
1. Click "Register" in the sidebar
2. Enter your details (username, email, password)
3. Click "Create Account"

### Step 4: Start Learning!
1. Log in with your credentials
2. Click "Courses" to view available courses
3. Start with "Python Fundamentals"
4. Complete lessons, exercises, and quizzes
5. Earn certificates!

## 🛠️ Customization

### Change Theme
Edit `.streamlit/config.toml` to customize:
- Color scheme
- Font
- Layout options

### Add New Courses
1. Edit `src/courses.py`
2. Add course content following existing format
3. Restart the app

### Extend Features
- Add new pages in `pages/` directory
- Update database schema in `src/db.py`
- Add new routes in `app.py`
